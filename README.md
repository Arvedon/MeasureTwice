# Measure Twice

[Play Measure Twice](https://arvedon.github.io/MeasureTwice/)

Practice reading rulers through Free Play, five open Learn lessons, and independent House, Plane, Chair and Tree challenges. Choose a visible graduation, commit the cut, inspect the result, and keep or retry the piece. Arrow keys, magnification and reduced motion are available. Progress saves in this browser; another device or site address has separate saved work.
